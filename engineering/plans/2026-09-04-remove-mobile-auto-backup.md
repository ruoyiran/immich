# 移除移动端自动备份实现计划

## 目标

- 删除移动端自动备份的入口、设置页面和后台执行链路。
- 应用升级后取消旧版本遗留的后台备份任务，并让已经被系统唤起的旧任务安全退出。
- 保留相册内手动上传、单个资产上传和系统分享入口上传。
- 保留历史配置及本地数据库字段，避免为已失效配置引入不必要的数据迁移风险。

## 实现步骤

1. 删除导航栏备份入口、设置页备份分组及所有自动备份路由和页面。
2. 删除启动、前后台切换、登录、WebSocket 和后台同步中的自动备份触发逻辑。
3. 删除自动备份专用 provider、repository、service 和关联测试；收窄前台上传服务，仅保留手动与分享上传能力。
4. 应用启动时取消历史后台任务；Android 不再主动调度备份任务；保留兼容回调但改为无上传的安全退出，以处理升级前已经排队的系统任务。
5. 重新生成路由代码，运行格式化、移动端单元测试、静态分析和 `git diff --check`。
6. 对完整 diff 做独立 code review，修复确认的问题后重新验证。

## 验收标准

- 移动端 UI 中不存在自动备份入口、相册选择、备份选项或备份状态页面。
- 冷启动、登录、恢复前台、WebSocket 事件和系统后台任务均不会启动照片自动备份。
- 手动上传和系统分享上传仍通过前台上传服务正常工作。
- 历史安装升级后，已有后台任务会被取消；竞态下已启动的旧任务不会上传文件。
