# Server Deployment

This repository no longer provides a Docker Compose stack or server container image.

Deploy the backend from the sibling `photo-classifier` repository. Its `README.md`, `.env.example`, and deployment documentation are the authoritative sources for MySQL, media storage, the Go API, the Rust pipeline, and external model services.

## Step 2 - Populate the .env file with custom values

Create and edit the backend `.env` inside `photo-classifier` by following that repository's setup instructions. Do not reuse the removed Immich Compose variables.

After deployment, configure the Web or Mobile client with the server URL. Local Web development defaults to `http://127.0.0.1:8080`.
